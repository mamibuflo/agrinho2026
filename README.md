# 🌱 EcoAgroForte

## Agro Forte, Futuro Sustentável

O **EcoAgroForte** é um projeto desenvolvido com o objetivo de demonstrar a importância da sustentabilidade na agricultura, promovendo o equilíbrio entre produção agrícola, preservação ambiental e inovação tecnológica.

O site apresenta informações sobre práticas sustentáveis no campo, impactos positivos para o meio ambiente e formas de contato com a equipe do projeto.

---

## 📋 Funcionalidades

* Página inicial com banner de destaque.
* Menu de navegação com ancoragem entre as seções.
* Seção "Sobre" apresentando o projeto.
* Seção de práticas sustentáveis.
* Seção de impacto esperado.
* Formulário de contato.
* Links para redes sociais.
* Design responsivo para computadores, tablets e celulares.

---

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* Google Fonts

## 🎯 Objetivo

Promover a conscientização sobre práticas agrícolas sustentáveis, incentivando a preservação dos recursos naturais e a utilização de tecnologias que contribuam para uma produção mais eficiente e responsável.

---

## 🤖 Uso de Inteligência Artificial

Este projeto contou com o apoio de ferramentas de Inteligência Artificial durante seu desenvolvimento.

A IA foi utilizada como ferramenta de apoio para:

* Organização da estrutura do site;
* Sugestões de design e estilização;
* Auxílio na escrita de códigos HTML, CSS e JavaScript;
* Revisão e otimização de componentes visuais.

Todo o conteúdo foi revisado, adaptado e validado pelos responsáveis pelo projeto.

---

## 👨‍💻 Desenvolvimento

Projeto acadêmico desenvolvido para fins educacionais, visando aplicar conhecimentos de desenvolvimento web e sustentabilidade no setor agrícola.
